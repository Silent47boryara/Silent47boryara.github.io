# Karaptic Research website

The live website is [karaptic.com](https://karaptic.com).

The complete current website source is stored in [`karaptic-site/`](./karaptic-site/). It includes:

- the generated static site in `dist/`;
- research and About content in `content/`;
- the build scripts in `scripts/`;
- the Karaptic favicon set and visual assets.

The files in the repository root are retained as redirects from the legacy GitHub Pages address to the canonical domain, avoiding duplicate indexed copies of the same website.

Future Karaptic website updates should be mirrored into `karaptic-site/` after deployment.
